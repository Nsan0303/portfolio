# pythonオンpythonオンリーでブログ作ってみた 20251211004512
初めまして、Nsanです。

今回は、このブログの動作確認もかねて記事を書いています。
あわせて「Pythonオンリーでブログを作るとどうなるのか」という、
個人的な検証の意味もあります。

この記事の内容は、このブログ自体についてです。

このブログは、タイトルにもある通り Pythonオンリーで作っています。
ただし、いわゆる「完全にPythonだけ」という意味ではなく、
データ保存にSQLite、表示部分にHTML/CSSは利用しています。

それでも、記事生成や構造の管理、処理の流れはすべてPythonで実装しています。

## なぜ作ろうと思ったか

少し前にポートフォリオ用のページを作っていた際、
ブログへのリンクを勢いで作ってしまいました。
消せばよいものを、深夜テンションでそのまま作り始めたのがきっかけです。

他にも理由はあります。
既存のCMSやブログシステムが、自分には使いにくかったり、
あまりしっくり来なかったりしました。

それなら、自分専用のシステムを作ってしまえばいいのでは、という
かなり脳筋な動機で作っています。

## なぜPythonオンリーで作ったか

答えはシンプルで、私がPythonしか書けないからです。
ある程度なんでもできてしまうPythonが悪いとも言えます。

また、「Pythonオンリーでブログを作ったら面白そう」
と思ったのも理由のひとつです。

## こだわったところ

WordPressなどのCMSを使った経験はあるのですが、
UI操作がどうにも合いませんでした。

そのため、CUIのみで完結するブログシステムを作りたいと思い、
極力UIを作らず、コマンド操作で完結する構成にしています。

また、Markdownで記事を書けるようにしています
（この記事もMarkdownで作っています）。

今後は Mermaid などのツールも導入していく予定です。

## このブログでやっていること

このシステムでやっていることは、ざっくり以下の通りです。

- 記事のドラフトを HTML または Markdown で作成する
- 執筆したファイルを読み込む
- Markdown の場合は HTML に変換する
- データベースで非公開状態を解除する

## 大変だった点

一番大変だったのは、SQLの文法でした。
全部大文字で書かれていたり、`VARCHAR`のような記法が出てきたりと、
最初は「これは何を意味しているのか」がまったく分かりませんでした。

特に、CREATE文やテーブル定義まわりは、
書き方のルールが多く感じてしまい、
Pythonのように直感的に書けない点に苦労しました。

最終的には「必要な最低限だけを使う」という割り切りで、
なんとか動くところまで持っていきました。
